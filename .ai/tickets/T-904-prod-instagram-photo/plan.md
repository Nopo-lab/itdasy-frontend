# T-904 운영 인스타 연결·최근 사진 수정 승격

사용자 2026-10-02 요청으로 운영 수정·검증된 최근 업데이트 반영 승인. 키·비밀번호·토큰 값 기록 금지. 운영 DB 직접 쓰기 금지.

1. 운영 이전 제공판·트래픽·환경 이름·시크릿 참조를 별도 안전한 운영 기록에 저장했다.
2. Meta 프로필 조회는 최신 연결200, 옛 연결401. callback .run 뒤 .app 누락은 DNS 실패로 확인했다.
3. 테스트 e7ee518에서 인스타 복귀, 사진편집 모듈, 누끼의 사진별 상태, 저장·재열기·임시 URL 복구를 선별 승격한다. 새 사진 편집 CSS와 로더 순서도 포함한다.
4. 운영 API 주소·Capacitor·Android/iOS·Play Integrity·결제·package/lockfile·기존 workflow는 유지한다. index는 사진 CSS/URL 복구 등록만 추가하고 Play Integrity 줄은 유지한다.
5. standalone oauth-return.html 저장 키가 staging으로 잘못 고정된 부분을 운영 prod 키로 맞춘다. 독립 페이지의 전용 상수로 참조하고 회귀 검사한다. URL 인증값은 계속 서버 교환 후만 저장한다.
6. 전체 자동 검사·회귀 검사·독립 리뷰 후 PR을 만든다. 기존 운영 Pages 배포를 확인하고 실제 제공 파일/복귀 응답을 검증한다. 네이티브 실기기·Meta 계정 재승인 성공은 따로 미확인으로 표시한다.

기존 큰 편집 파일은 검증된 버전을 가져오며 새 구현을 압축하지 않는다. 독립 편집 모듈 경계는 테스트판 그대로 유지한다.
