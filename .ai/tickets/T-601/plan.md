# T-601 실행 계획

1. 원격 최신 작업실 코드와 현재 앱 연결 파일을 기준으로 기능을 다시 추적한다.
2. 기존 저장·재편집·캐러셀·출력 계약을 건드리지 않는 작은 연결로 스타일 동의와 안전 규칙을 붙인다.
3. 새 글자 기본 위치, 뷰티 보정, 살롱 스티커를 현재 사진편집기에 추가한다.
4. 스타일 기억은 계정·업종·게시 목적을 모두 맞춰 추천하고, 원장이 직접 자동 적용을 켠 경우에만 자동으로 적용한다.
5. 추천 적용 뒤에는 시간 제한 없이 편집기에서 뺄 수 있게 하고, 되돌리기/다시 실행과 학습 기록도 같은 상태로 맞춘다.
6. 자동 확인, 모바일 크기 실제 브라우저, 최신 스테이징 배포, iPhone/Android 앱 순으로 확인한다.
7. 실제 고객 자료나 공개 발행 없이 합성 QA 사진과 별도 QA 상태만 사용한다.

## 예상 위험

- 기억한 업종이 다른 사진에 섞이는 문제
- 보정이나 꾸밈을 뺐는데 학습 기록에는 수락으로 남는 문제
- 보정만 쓴 원장 스타일이 기억에서 빠지는 문제
- 현재 작업실 대신 옛 화면을 검사하는 문제
- 저장·재편집 때 사진에 보정이 두 번 들어가는 문제

## 막는 방법

- 같은 계정·업종·게시 목적을 모두 확인한다.
- 자동 적용 기본값을 끈다.
- 기억에서 온 항목만 표시하고 한 덩어리로 뺀다.
- 보정은 숫자 전체가 아니라 앱 프리셋 이름과 강도만 기억한다.
- `origin/main` 최신 작업실과 앱이 실제 불러오는 주소를 기준으로 확인한다.
