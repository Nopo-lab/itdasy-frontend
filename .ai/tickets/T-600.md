# T-600 — 사진편집 경쟁력 강화

## 배경

원장님들이 Meitu, BeautyPlus, Facetune, YouCam, EPIK, SNOW, Photoroom, CapCut 같은 앱을 따로 켜지 않고, 잇데이 안에서 홍보 사진을 끝낼 수 있게 만든다.

## 목표

- 사진 전체가 아니라 피부, 머리, 눈, 손, 네일, 배경을 더 정확히 구분한다.
- 메뉴를 기능 나열이 아니라 원장님 작업 순서로 정리한다.
- 기본 보정은 빠르게, 오래 걸리는 AI는 명확히 분리한다.
- 실제 네일/헤어/속눈썹/피부 사진으로 깨짐과 렉을 확인한다.

## 이번 작업 범위

1. 빠른 영역 보정 안전장치 추가
   - 피부 보정이 배경으로 새는 문제 줄이기
   - 모발 보정이 배경/검은 옷으로 새는 문제 줄이기
   - 눈/속눈썹 보정이 머리카락·로고에 과하게 먹는 문제 줄이기

2. UX 정리
   - 느린 AI와 빠른 보정을 화면에서 분리
   - 추천 보정 문구를 원장님이 바로 이해하는 말로 정리
   - 중복 기능은 첫 화면에서 숨기고 세부 도구로 묶기

3. 검증
   - 브라우저에서 사진 열기, 자동보정, 디테일, 템플릿, 저장 흐름 확인
   - 기존 자동 검사 실행

## 보류

- 돈 드는 생성형 AI 지우기 / 고급 업스케일 / AR 가상시술은 이번 커밋에 넣지 않는다.
- 실제 서버 과금이 필요한 기능은 별도 승인 후 진행한다.
