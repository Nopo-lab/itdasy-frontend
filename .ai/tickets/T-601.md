# T-601 — 최신 작업실 사진편집 원장 스타일 업그레이드

## 목표

현재 앱에서 쓰는 작업실과 사진편집기를 유지하면서, 원장이 자주 쓰는 편집 감각을 안전하게 기억하고 다음 같은 업종·같은 게시 목적에 한 탭으로 다시 쓸 수 있게 한다.

## 범위

- 원장 동의 뒤에만 스타일 기억
- 자동 적용 기본 꺼짐, 추천과 자동 적용을 따로 제어
- 계정·업종·게시 목적이 다르면 추천/자동 적용 금지
- 보정만 한 편집도 기억하고 적용·빼기 지원
- 살롱 스티커 29개와 뷰티 보정 9개
- 새 글자 하단 안전영역과 기본 그림자
- 현재 작업실 카드·설정 문구 정리
- 저장·재편집·캐러셀·출력 크기 등 기존 통과 기능 회귀 확인

## 제외

- 옛 사진편집기, 옛 템플릿, 옛 자르기/마스크 화면 부활
- 예약·고객·매출·회원권 변경
- 실제 고객 사진/게시물/운영 데이터 변경
- Meta 실제 공개 발행

## 완료 조건

- 전체 자동 확인과 현재 작업실 흐름 확인 통과
- 최신 스테이징 배포 뒤 iPhone/Android 앱에서 현재 화면 확인
- 안전한 QA 데이터로 적용·빼기·저장 결과 확인
- 확인하지 못한 항목이 있으면 GREEN으로 보고하지 않음
