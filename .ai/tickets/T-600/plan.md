# Plan — T-600 Photo Editor Competitive Upgrade

## 1차 구현

- 새 파일 `app-photo-editor-smart-mask.js` 추가
- 기존 큰 파일에는 연결선만 추가
- 사진 안의 피부/머리/눈/네일/배경 가능성을 빠르게 계산해서 보정이 엉뚱한 곳으로 새지 않게 한다

## 2차 구현

- 사진편집 메뉴 문구 정리
- 추천 보정 카드를 업종별로 더 앞에 보여준다
- 느린 정밀 AI는 `느림` 표시를 더 명확히 한다

## 3차 구현

- 실제 사진 자동 검증 보강
- 큰 사진, 템플릿, 디테일 보정, 저장 흐름 검사

## 2026-05-21 진행 결과

- 1차/2차/3차 기본 범위 진행 완료.
- 실제 사진 QA: 네일 5장 / 헤어 4장 / 피부 1장 + 템플릿 30종 통과.
- 브라우저 심각 오류 0개, 깨짐 실패 0개.
- 다음은 실제 원장님 사진 사람 눈 검수와 유료 AI 기능 결정.

## 위험

- 지금 사진편집 큰 파일들은 이미 길어서 새 기능을 직접 넣으면 유지보수가 어려워진다.
- 외부 AI 모델은 첫 로딩이 길 수 있으므로 기본 보정에는 쓰지 않는다.
- 영역 판단이 너무 강하면 보정 체감이 약해질 수 있어, 안전장치 강도는 보수적으로 시작한다.
