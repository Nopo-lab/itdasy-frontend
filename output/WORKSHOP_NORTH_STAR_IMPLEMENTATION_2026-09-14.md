## STYLE MEMORY SAFETY

- 새 정책 파일에서 업종, 게시 목적, 동의 버전, 계정, 자동 적용 자격을 한 번에 판정한다.
- 저장 레코드에 `industry`, `occasion`, `consentVersion`, `autoApplyAllowed`, `createdFrom`, `createdAt`, `ownerId`를 남긴다.
- 업종이나 목적을 알 수 없는 기록, 옛 기록, 계정 주인이 다른 기록은 자동 적용 후보에서 제외한다.
- 원장 스타일의 글자·스티커·배치와 앱 프리셋 보정만 재사용한다. 사진, 붓그림, 원본 보정 숫자, 확대 위치는 다른 사진으로 복사하지 않는다.

## CONSENT UX

1. 저장·발행 준비 뒤 기억할 편집이 있으면 “이번 스타일을 기억할까요?”를 묻는다.
2. `[이번만]`은 저장하지 않는다.
3. `[기억하기]`는 스타일만 저장한다.
4. 이어서 “다음 ○○ 사진에 자동으로 적용할까요?”를 별도로 묻는다.
5. `[추천만 보기]`와 `[자동 적용 켜기]`를 분리했다.

`기억하기`가 자동 적용 동의로 바뀌지 않는다.

## AUTO APPLY

- 기본값은 꺼짐이다.
- 자동 적용은 원장이 두 번째 선택이나 설정에서 직접 켰을 때만 동작한다.
- 추천을 끄면 자동 적용도 함께 꺼진다.
- 자동 적용을 다시 켜면 동의가 유효한 현재 계정의 기억만 허용한다.

## INDUSTRY / OCCASION ISOLATION

자동 적용은 아래가 모두 같을 때만 허용한다.

- 같은 계정
- 같은 업종
- 같은 게시 목적
- 현재 동의 버전
- 자동 적용 허용 기록
- `unknown`과 옛 기록이 아님

업종 9개와 게시 목적 7개를 서로 전부 교차한 검사에서 다른 칸의 기억이 후보에 들어오지 않았다. `forEditor`와 `decorateLayers`는 같은 선택 함수를 사용한다.

## ADJUSTMENT PRESET MEMORY

- 원본 `brightness`, `contrast`, `saturation`, `temperature`, `sharpness` 숫자는 작업기억에 넣지 않는다.
- 원장이 누른 `presetId`와 `presetStrength`만 기억한다.
- 프리셋 적용 뒤 숫자를 직접 바꾸거나 초기화하면 프리셋 표시를 해제한다.
- 저장·재편집용 편집 상태에는 현재 사진의 실제 보정값이 그대로 유지된다. 다른 사진 자동 적용에는 쓰지 않는다.
- 보정만 기억한 스타일도 다음 사진에 적용되고, `이번 스타일 빼기`와 되돌리기로 원복된다.
- 저장본을 다시 열면 선택했던 보정 프리셋 버튼이 선택 상태로 표시된다.
